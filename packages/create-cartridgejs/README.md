# create-cartridgejs

Start a new three.js game that ships to Steam with cartridge.js.

```bash
npm create cartridgejs@latest my-game
cd my-game
npm install
npm run desktop:dev
```

Also works with `pnpm create cartridgejs`, `yarn create cartridgejs` and `bun create cartridgejs`.

Docs: https://github.com/frg100/cartridgejs#readme · MIT
