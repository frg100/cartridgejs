# @cartridgejs/create

Start a new three.js game that ships to Steam with cartridge.js.

```bash
npm create @cartridgejs@latest my-game
cd my-game
npm install
npm run desktop:dev
```

Also works with `pnpm create @cartridgejs my-game` and `yarn create @cartridgejs my-game`.
(npm, pnpm and Yarn run the package `@cartridgejs/create` when you give only the scope.)

Docs: https://github.com/frg100/cartridgejs#readme · MIT
