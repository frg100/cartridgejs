# @cartridgejs/electron

The Electron shell that `@cartridgejs/cli` uses to run and package cartridge.js games: the game window,
the `app://game/` protocol, and the Steamworks bridge (steamworks.js).

You do not install or import this package yourself. `@cartridgejs/cli` depends on it.

Architecture: https://github.com/frg100/cartridgejs/blob/main/docs/architecture.md · MIT
